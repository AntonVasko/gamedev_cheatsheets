Первая программа

Entity — основа всего: любой предмет сцены. Разбираем, как создать объект и оживить его.

Добавление объектов#

Создали Entity — он сразу в сцене. Для своих типов наследуйтесь.

Настройка#

Окно настраивается через window.

Модель#

Встроенные: cube, sphere, quad, plane, circle, diamond. Свои — .obj/.glb из проекта.

Текстура#

Встроенная (brick, grass…) или своя картинка.

Цвет#

Цвет умножается на текстуру.

Положение#

Позиция — (x, y, z). Можно менять по осям отдельно.

Вращение#

Углы в градусах по осям x, y, z.

Масштабирование#

Одно число — равномерно, тройка — по осям.

Обновление#

update() вызывается каждый кадр. Умножайте на time.dt, чтобы скорость не зависела от FPS.

События клавиатуры#

input(key) — на нажатие; held_keys — пока клавиша зажата.

События мыши#

Для on_click объекту нужен коллайдер.

Другие «волшебные» функции#

Методы у Entity вызываются движком сами; плюс удобные помощники.

Пример: готовая программа#

Сохраните код как main.py в отдельной папке и запустите.

Частые ошибки#

  • Двигайте объекты через time.dt — иначе на быстром ПК всё будет «летать».
  • on_click и mouse.hovered_entity не работают без collider.
  • update и input вне класса — глобальные; внутри Entity это методы self.
