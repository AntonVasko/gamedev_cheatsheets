Сеть

Ursina работает по TCP: один участник — хост (сервер), остальные подключаются по IP и порту. Основной инструмент — удалённый вызов функций (RPC).

Идея#

Функцию помечают @rpc(peer) — и её можно вызвать с другого компьютера. Данные упаковываются автоматически.

Объявление RPC#

Аннотации типов у аргументов обязательны.

Цикл и вызов#

Событий сети не будет, пока вы не вызываете peer.update() каждый кадр.

Запуск#

Хост — is_host=True, клиент — False и IP хоста.

Через интернет#

Нужен проброс порта на роутере хоста и разрешение в фаерволе. Без этого работает только в локальной сети.

Примеры из поставки#

hello_world.py (низкоуровневый Peer), hello_world_rpc.py, shared_object.py, host_authoritative.py, club_bear.py (полноценная игра).

Альтернатива#

Сторонняя событийная библиотека ursinanetworking (pip install ursinanetworking): UrsinaNetworkingServer/Client, send_message(), process_net_events().

Пример: готовая программа#

Сохраните код как main.py в отдельной папке и запустите.

Частые ошибки#

  • Нет аннотации типа у аргумента RPC — вызов не сработает.
  • Не вызывали peer.update() — ни подключений, ни сообщений.
  • Клиент запущен раньше хоста или порт занят/закрыт фаерволом — подключения не будет.
  • Слать позицию каждый кадр — только для демо; в игре ограничьте частоту.
